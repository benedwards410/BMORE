# BGE Application Center: Lighting Application fields

From the portal screenshots (hpwescontractor.customerapplication.com). The cheat sheet
(`portal_sheet.py`) prints these in this order with the value and its source.

1. **Savings and Incentive Information**: Total Requested Incentive (workbook *Measure Codes
   Summary Table* L99), Total Estimated kWh Savings (L100). Both come from the Excel-saved file.
2. **Project Information**: Title of Utility Customer · Application is being completed by ·
   Application Date · National Account (Yes/No) · Installation Contractor, Retrofit Lighting ·
   self-install lead name (N/A when a contractor is picked) · Installation Contractor, Sign
   Lighting · self-install name (sign) · Business Type (Minority-/Woman-/Veteran-owned) ·
   Business Sector · If other, specify · Building Type (Office, Retail, School, University,
   Religious Facility, Grocery, Lodging, Industrial, Warehouse, Health Facility, Multifamily,
   Restaurant, Other) · If other, specify · Square Footage By Application.
3. **Payee Information**: Check Payable To (Customer / Contractor / Third Party) · Check Payable
   Name · Payee Contact Name · Payee Address · Address Continued · City · State · Zip.
4. **Document Upload**: Manufacturer's Cut Sheets · Retrofit Lighting Worksheet (both required).
   The customer-signed T&C is also required by BGE's checklist. If the portal has no slot for it,
   send it to Business@BGESmartEnergy.com.

Workbook building types map to portal radio buttons one-to-one, except
"Health Facilities" → "Health Facility".
